## ⚙️ Installation

```bash

```

### 2️⃣ Open Project Folder

```bash
cd multiplication-table
```

### 3️⃣ Install Flask

```bash

```

### 4️⃣ Run the Application

```bash
python main.py
```

### 5️⃣ Open Browser

```
http://127.0.0.1:5000/
```

---

## 🚀 How It Works

1. Enter a number.
2. Click **Generate Table**.
3. The Flask backend receives the input.
4. Python generates the multiplication table.
5. The result is displayed instantly on the webpage.
